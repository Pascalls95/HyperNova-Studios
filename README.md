# HyperNova-Studios
This is a website that I created to hypothetically 'market' 3 games in a 'game studio' that were made by 2 other people (the games themselves, the website was done by myself) for #horizons. I did this project to help learn more about HTML and CSS in a fun and interesting way, and how to use it to make an aesthetically pleasing website. The website consists of several different pages: A home page, catalogue, checkout, and pages for each of the individual games. The user starts on the home page and can navigate through the website either through the navigation bar or through the game cards that are presented on the home page. 

To run the project, simply open the deployed link that has been provided, and work your way through the website.

AI was partially used in this project, only to learn how to style and format certain things that I did not know how to do. For example, how to add a nice box shadow.
