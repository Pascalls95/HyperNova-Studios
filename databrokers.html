Data Brokers

Your only job is to get rich. Buy personal data. Sell personal data. Engage in trade on the Dark Web, and most importantly;

Don't Go Bankrupt!

Synopsis

You are dirt broke, and you need money. Fast.

Luckily for you, selling people's personal data on the Dark Web gets the job done quickly. Buy data from data vendors, process the data to make it usable, and sell it to shady criminal groups to make a profit. But beware, as the more you earn, the harder it is to keep earning.

Learn about real economic strategies, and learn what really happens to your sensitive information online.

How to Play

Controls

This game is entirely played using a mouse, there is little to no keyboard support

Platform Requirements

Requires an operating system with a compatible browser (chromium/gecko based, can run javascript and css)

Compatible Operating Systems

Literally anything that can run a browser (Windows, MacOS, Android, Linux, etc)
